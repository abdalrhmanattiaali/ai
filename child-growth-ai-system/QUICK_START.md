## خطوات التشغيل السريع (5 دقائق)

### 1️⃣ التثبيت

```bash
cd child-growth-ai-system
npm install
```

### 2️⃣ الإعداد

أنشئ ملف `.env` ببساطة:

```bash
cp .env.example .env
```

افتح `.env` وأضف مفتاح AI الخاص بك (واحد فقط):

#### خيار أ: استخدام OpenAI
```env
AI_PROVIDER=openai
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxx
```

#### خيار ب: استخدام Anthropic Claude
```env
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxx
```

### 3️⃣ إنشاء قاعدة البيانات

```bash
npm run init-db
```

### 4️⃣ التشغيل

```bash
npm start
```

### 5️⃣ الاتصال

1. **امسح QR Code**: سيظهر في Terminal
2. **افتح المتصفح**: `http://localhost:3000`
3. **أدخل البيانات**: في تبويب "الإعدادات"
4. **استمتع بالنظام**! 🎉

## ⚡ الحصول على مفاتيح API

### OpenAI (الخيار الأسهل)

1. اذهب إلى: https://platform.openai.com/api-keys
2. سجل دخول أو أنشئ حساب
3. اضغط "Create new secret key"
4. انسخ المفتاح وضعه في `.env`

💰 **السعر**: ~$0.01 لكل 1000 رسالة (رخيص جداً)

### Anthropic Claude (أقوى ولكن أغلى قليلاً)

1. اذهب إلى: https://console.anthropic.com
2. سجل دخول أو أنشئ حساب
3. اذهب إلى API Keys
4. أنشئ مفتاح جديد
5. انسخه وضعه في `.env`

### OpenWeatherMap (اختياري - للطقس)

1. اذهب إلى: https://openweathermap.org/api
2. سجل مجاناً
3. احصل على API Key
4. أضفه في `.env`:

```env
WEATHER_API_KEY=xxxxxxxxxx
WEATHER_CITY=Cairo,EG
```

🆓 **مجاني تماماً!** (1000 طلب يومياً)

## 🎯 الاستخدام الأساسي

### من المتصفح (لوحة التحكم)

1. **الإعدادات**: أدخل معلومات الطفل والوالدين
2. **لوحة المعلومات**: شاهد الإحصائيات والطقس
3. **الجدولة**: تحكم في مواعيد الرسائل
4. **الأنشطة**: تتبع الأنشطة المقترحة
5. **الذاكرة**: اطّلع على سجل المحادثات
6. **الذكاء الصناعي**: احصل على توصيات فورية

### من واتساب (للوالدين)

أرسل أي رسالة وسيرد الذكاء الصناعي!

أو استخدم الأوامر:
- `/help` - المساعدة
- `/info` - معلومات الطفل
- `/tips` - نصائح
- `/activities` - أنشطة مقترحة
- `/books` - كتب مقترحة
- `/weather` - حالة الطقس

## 🛠️ حل المشاكل السريع

### المشكلة: "npm install فشل"

```bash
# احذف المجلد وحاول مرة أخرى
rm -rf node_modules
npm install
```

### المشكلة: "QR Code لا يظهر"

```bash
# احذف مجلد الاتصال وحاول مرة أخرى
rm -rf .wwebjs_auth .wwebjs_cache
npm start
```

### المشكلة: "AI لا يرد"

1. تحقق من مفتاح API في `.env`
2. تأكد من وجود رصيد في حسابك
3. تحقق من اتصال الإنترنت

### المشكلة: "الرسائل لا تُرسل"

1. تأكد من اتصال واتساب (شاشة Dashboard)
2. تحقق من صحة أرقام الهواتف
3. افتح واتساب على الهاتف وتأكد من الاتصال

## 💡 نصائح مهمة

### 1. لا تغلق Terminal

النظام يعمل في Terminal - إبقاءه مفتوحاً طوال الوقت.

### 2. احفظ مفاتيح API بأمان

لا ترفع ملف `.env` إلى Git أبداً!

### 3. استخدم `npm run dev` للتطوير

سيعيد التشغيل تلقائياً عند أي تعديل.

### 4. راقب الإحصائيات

Dashboard يعرض كل شيء في الوقت الفعلي.

### 5. اجعل الجدولة معقولة

لا تُرسل رسائل كثيرة جداً - احترم وقت الوالدين!
