# 🧙‍♂️ دليل معالج الإعداد - Setup Wizard Guide

---

## 🎯 نظرة عامة

معالج الإعداد هو واجهة ويب تفاعلية تمكنك من إعداد نظام رفيق النمو بالكامل من خلال متصفح الويب فقط، دون الحاجة لتعديل ملفات أو كتابة أوامر يدوية.

✅ **إعداد كامل من الويب** - لا حاجة لتعديل ملفات يدوياً
✅ **دعم MySQL** - يعمل مع قواعد بيانات MySQL على الاستضافات
✅ **اختبار الاتصالات** - تحقق من صحة الإعدادات قبل الحفظ
✅ **واجهة بسيطة** - خطوات واضحة ومرتبة
✅ **توليد تلقائي** - يُنشئ ملف .env تلقائياً
✅ **مُتعدد الخطوات** - 5 خطوات منظمة

## 🚀 كيفية الاستخدام

### الخطوة 1️⃣: تثبيت Dependencies

```bash
cd child-growth-system

# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

### الخطوة 2️⃣: تشغيل Backend و Frontend

**في Terminal أول (Backend):**
```bash
cd backend
npm run dev
```
يجب أن ترى:
```
Server running on port 5000
```

**في Terminal ثاني (Frontend):**
```bash
cd frontend
npm run dev
```
يجب أن ترى:
```
Ready on http://localhost:3000
```

### الخطوة 3️⃣: فتح معالج الإعداد

افتح المتصفح وانتقل إلى:
```
http://localhost:3000/setup
```

## 📋 خطوات معالج الإعداد

### الخطوة 1: إعداد قاعدة البيانات MySQL

<div dir="rtl">

املأ بيانات قاعدة بيانات MySQL:

| الحقل | الوصف | مثال |
|-------|-------|------|
| **عنوان الخادم** | Host أو IP للاستضافة | `localhost` أو `mysql.yourdomain.com` |
| **المنفذ** | Port الافتراضي | `3306` |
| **اسم قاعدة البيانات** | Database Name | `child_growth_system` |
| **اسم المستخدم** | Username | `root` أو اسم المستخدم من لوحة الاستضافة |
| **كلمة المرور** | Password | كلمة مرور قاعدة البيانات |

**🔍 زر اختبار الاتصال:**
- اضغط "اختبار الاتصال" للتحقق من صحة البيانات
- ستظهر رسالة نجاح ✅ أو خطأ ❌

</div>

#### 💡 إنشاء قاعدة البيانات

إذا لم تكن قاعدة البيانات موجودة، أنشئها أولاً:

**عبر phpMyAdmin:**
1. افتح phpMyAdmin
2. اضغط "New" لإنشاء قاعدة جديدة
3. اسم القاعدة: `child_growth_system`
4. Collation: `utf8mb4_unicode_ci`
5. اضغط "Create"

**عبر Terminal:**
```bash
mysql -u root -p
CREATE DATABASE child_growth_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

## 📁 ما الذي تم إنشاؤه؟

معالج الإعداد يقوم بـ:

### 1. إنشاء ملف `.env`:
```env
# تم إنشاؤه تلقائياً بواسطة Setup Wizard

DB_TYPE=mysql
DB_HOST=your-host
DB_PORT=3306
DB_NAME=child_growth_system
DB_USER=your-username
DB_PASSWORD=your-password

OPENAI_API_KEY=your-key
OPENWEATHER_API_KEY=your-key

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email
SMTP_PASS=your-password

ADMIN_USERNAME=admin
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=hashed-password

SETUP_COMPLETE=true
```

### 2. إنشاء جداول قاعدة البيانات:
- `users` - المستخدمون
- `families` - الأسر
- `children` - الأطفال
- وجداول أخرى...

### 3. إنشاء المستخدم الإداري:
- حساب بصلاحيات Admin
- يمكنه الوصول لكل المميزات

## 🔧 استكشاف الأخطاء

### ❌ "فشل الاتصال بقاعدة البيانات"

**الأسباب المحتملة:**
1. MySQL غير مشغل
2. بيانات الاتصال خاطئة
3. قاعدة البيانات غير موجودة
4. المستخدم ليس لديه صلاحيات

**الحلول:**
```bash
# تأكد من تشغيل MySQL
sudo systemctl status mysql

# أو
sudo systemctl start mysql

# تحقق من إمكانية الاتصال
mysql -h localhost -u root -p
```

---

### ❌ "قاعدة البيانات غير موجودة"

**الحل:** أنشئ قاعدة البيانات أولاً:
```sql
CREATE DATABASE child_growth_system
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

---

### ❌ "Access Denied"

**المشكلة:** اسم المستخدم أو كلمة المرور خاطئة

**الحل:**
1. تحقق من بيانات الاتصال
2. تأكد من صلاحيات المستخدم:
```sql
GRANT ALL PRIVILEGES ON child_growth_system.*
TO 'your_user'@'localhost'
IDENTIFIED BY 'your_password';

FLUSH PRIVILEGES;
```

---

### ❌ "OpenAI API فشل"

**الأسباب:**
1. المفتاح غير صالح
2. نفد الرصيد
3. القيود (Rate Limits)

**الحل:**
- تحقق من المفتاح في [platform.openai.com](https://platform.openai.com)
- تأكد من وجود رصيد
- أو اترك الحقل فارغاً (اختياري)

## 🌐 للاستخدام مع استضافة خارجية

### إذا كانت قاعدة البيانات على استضافة:

1. **احصل على بيانات الاتصال من لوحة الاستضافة:**
   - Host (مثلاً: `mysql.yourdomain.com`)
   - Port (عادة `3306`)
   - Username
   - Password
   - Database Name

2. **أدخلها في معالج الإعداد**

3. **تأكد من السماح بالاتصال الخارجي:**
   - بعض الاستضافات تتطلب إضافة IP للقائمة البيضاء
   - تحقق من cPanel → Remote MySQL

## 📊 الفرق بين MongoDB و MySQL

| الميزة | MongoDB | MySQL |
|--------|---------|-------|
| **النوع** | NoSQL | Relational SQL |
| **التثبيت** | يحتاج تثبيت منفصل | متوفر مع معظم الاستضافات |
| **الاستخدام** | مشاريع كبيرة | مشاريع صغيرة/متوسطة |
| **الإعداد** | معقد قليلاً | سهل |
| **الاستضافة** | نادراً متوفر | متوفر دائماً |

**التوصية:** استخدم MySQL إذا كان لديك استضافة تقليدية.
